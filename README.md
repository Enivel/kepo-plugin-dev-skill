# Kepo Plugin Dev Skill

Agent Skill for developing, debugging, validating, locally installing, and publishing Kepo plugins.

## Install

Install with the `skills` CLI:

```bash
npx skills add Enivel/kepo-plugin-dev-skill --skill kepo-plugin-dev
```

Install globally for Codex:

```bash
npx skills add Enivel/kepo-plugin-dev-skill --skill kepo-plugin-dev --global --agent codex
```

## Skills

- `kepo-plugin-dev`: Workflow guidance for Kepo plugin development, local verification, and publishing.
